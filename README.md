# Zhengxin Ye | Developer Portfolio

A modular, responsive personal portfolio website built to showcase my software engineering projects, technical skills, and vocational training experience.

## 🚀 Tech Stack
* **HTML5:** Semantic structure and accessible markup.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and BEM-style class naming for maintainable styling.
* **JavaScript (ES6+):** Vanilla JS for DOM manipulation, event-driven UI updates, and async form handling.
* **Web3Forms:** Serverless contact form submission via the Fetch API.

## 📂 Project Structure
The project avoids heavy frontend frameworks in favor of a clean, vanilla architecture:
* `/src/styles/` - Global CSS tokens and responsive layout rules.
* `/src/components/` - Reusable UI logic (e.g., Web3Forms API integration).
* `/src/sections/` - Section-specific interaction logic.
* `/src/assets/` - Static files, PDF documents, and optimized images.
